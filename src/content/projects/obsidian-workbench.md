Obsidian 研究工作台（Normal）是一个桌面端插件，用于集中管理论文、阅读笔记、日记、待办和研究记录。

插件提供统一主页，将论文阅读和日常安排放在同一个界面中。笔记保存在本地仓库，使用 Markdown 编写；论文通过本地 PDF 文件关联，仍可从 Obsidian 文件列表直接打开。

## 主要功能

| 模块 | 功能 |
| --- | --- |
| 论文管理 | 识别论文链接，整理基本资料，按方向、状态和文件夹筛选 |
| 阅读与笔记 | 关联本地 PDF，并排打开论文和笔记，从论文创建思考记录 |
| 日记与待办 | 在日记中显示当天任务，修改日期、记录进展、同步完成状态 |
| 研究记录 | 集中查看实验、知识地图和研究计划 |
| 周总结与统计 | 汇总每周任务结果，通过日历和热力图查看记录 |
| 外观与扩展 | 切换主题和深浅色，配合 Tasks 与 Codex Panel 使用 |

## 论文管理

添加论文时，可输入 DOI、arXiv 编号或论文页面链接，识别标题、作者、年份和摘要。插件根据关键词提供研究方向建议，所有资料均可手动修改。

每篇论文对应一份笔记，可设置阅读状态、进度和重读日期。论文页支持多层文件夹，以及标题、作者、方向和阅读状态筛选。

PDF 由用户手动添加或更换，支持关联已有的中英对照 PDF。点击“PDF 与笔记”可并排阅读和记录，点击“写思考”可创建关联的思考笔记。

链接识别只获取公开论文资料，不下载或翻译 PDF。阅读进度由用户维护。

## 日记与待办

待办使用一份 Markdown 任务源，主页和日记显示同一条任务。在任一入口勾选完成，都会更新源任务并记录完成日期，无需重复维护多份清单。

### 日期规则

添加任务时，可设置开始显示日期、可选截止日期和任务背景。开始日期默认今天，不能晚于截止日期。

| 任务状态 | 显示方式 |
| --- | --- |
| 尚未开始 | 在待办页查看，暂不进入当天日记 |
| 已开始且未截止 | 每天进入“今日计划” |
| 已过截止日但未完成 | 进入“遗留任务” |
| 未设置截止日 | 从开始日期起持续显示，直到完成 |
| 已完成 | 保留在完成当天的记录中，之后的日记不再显示 |

例如，一项任务从 10 月 21 日开始、10 月 25 日截止，会在这段时间每天显示。如果 23 日完成，24 日起就不再显示；如果到 26 日仍未完成，则进入遗留任务。

开始日期可以在日记或待办页直接修改。取消完成后，任务重新按日期规则显示。

### 任务进展

每项任务可查看“任务背景与进展”，其中的相关笔记和历史记录保留可点击来源。“记录进展”支持进行中、受阻、调整安排和已完成，进度百分比可选填。

任务区与日记正文分开管理，不会将任务全文重复复制到每天的日记中。修改日期或完成状态后，历史日记中的任务视图也会按最新规则更新。

### 日记创建

“今日日记”用于创建或打开当天日记。日历中的其他日期只打开已有记录，没有记录时不创建空文件。未来日记不会提前生成，之后打开时再带入对应任务。

## 研究与回顾

研究页集中展示论文方向、实验记录、知识地图和研究计划，方便从阅读笔记继续整理问题、记录实验。

周总结按任务的显示区间统计计划，按完成日期统计结果，并列出未完成和结转任务。已结束的周保存结算快照，之后修改、重开或删除任务，不会改写已结算的结果。文字总结和下周重点由用户填写。

日历和热力图根据本地记录生成。日记统计排除空白模板和自动生成的任务区，任务统计依据源任务、完成日期和周结算记录。

## 本地上下文

插件在 `空间/上下文/memory.md` 中维护背景信息和记录摘要。

- **长期背景**：由用户填写近期重点、固定安排等信息。
- **自动摘要**：从有正文的日记、论文笔记中的基本资料与个人思考、聊天笔记和任务反馈中提取，并保留来源。
- **侧栏对话**：启用相关设置后，可采集当前仓库中已加载、已完成的 Codex 对话，不扫描账户全局历史。

摘要提取在本地完成，不读取 PDF 正文，也不会自动向 AI 接口发送记忆内容。可在设置中调整摘要长度，或关闭上下文和对话采集。

当前版本使用本地日期规则显示任务，不调用 AI 自动排期。

## 可选集成

### Tasks

可配合 Tasks 插件和任务检索页，按当前可做、未来开始、已完成、无截止日等条件查看任务。检索结果中的勾选会回写源任务，也可使用 Tasks 编辑器修改任务。

任务使用 Markdown 复选框和日期标记：

```markdown
- [ ] 阅读论文的方法部分 🛫 2026-10-21 📅 2026-10-25 ➕ 2026-10-20 <!-- task:固定标识 -->
```

`🛫` 表示开始日期，`📅` 表示截止日期，`➕` 表示创建日期，完成后使用 `✅` 记录完成日期。隐藏标识用于关联任务，日常操作通过界面完成即可。

Tasks 检索需要另外安装 Tasks，并配置任务检索页。

### Codex Panel

主页提供 AI 侧栏入口，需要另外安装并配置 Codex Panel。

配合带有论文连接工具的 Codex Panel 版本，可向助手提供当前论文、PDF 页码、选中文字及关联笔记，便于围绕正在阅读的内容提问。该能力由配套侧栏提供，普通 Codex Panel 版本是否支持取决于其实现。

侧栏问答独立运行，使用所配置的 Codex 服务；任务管理和日记功能不依赖侧栏。

## 主题与界面

提供日常、爱弥斯和卢迪乌斯主题，支持独立切换浅色与深色。主题图片保存在本地附件目录，可配置横幅和头像；有多个横幅时可点击切换。

设置中可调整空间名称、是否启动时打开主页，以及是否显示日历和热力图。

## 使用流程

1. 通过侧边栏图标或“打开个人主页”命令进入工作台。
2. 在“论文”页添加论文资料，选择本地 PDF，打开论文与笔记开始阅读。
3. 在“待办”页添加任务，设置开始日期和可选截止日期。
4. 打开“今日日记”，查看当天任务、记录进展和日常内容。
5. 在“周总结”页查看任务结果，补充回顾和下周安排。

## 数据保存

笔记和 PDF 保存在当前 Obsidian 仓库中，任务反馈与周结算等辅助数据使用本地 JSON 文件保存。

| 内容 | 默认位置 |
| --- | --- |
| 日记与思考 | `日记/`、`思考/` |
| 论文与实验笔记 | `论文/`、`实验/` |
| 知识地图与研究计划 | `知识地图/`、`研究计划/` |
| 待办源清单 | `待办/待办清单.md` |
| 周回顾 | `回顾/` |
| 本地上下文 | `空间/上下文/memory.md` |
| 任务反馈与周结算 | `空间/任务数据/` |

备份时应同时保留笔记、附件和任务数据，确保历史进展及周结算记录完整。

## 运行要求

- 当前插件版本：`2.3.0`，插件 ID：`normal-space`。
- 工作台仅支持 Obsidian 桌面端；插件声明的最低版本为 `1.11.4`。
- Tasks 为可选依赖。本机使用的 Tasks `8.6.0` 要求 Obsidian `1.13.1` 或更高版本。
- Codex 侧栏及论文连接能力需要对应的配套插件和服务配置。
- 论文链接识别需要联网；日记、任务日期计算和本地摘要整理不需要 AI API。
